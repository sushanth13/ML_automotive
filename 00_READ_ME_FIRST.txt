READ ME FIRST

Welcome to the Automotive ML Conversion Predictor project.

This directory contains a complete Machine Learning application that predicts automotive lead conversion probabilities using a Gradient Boosting model. 

1. Please read START_HERE.md for an overview.
2. Read QUICKSTART.md for instructions on how to run the application immediately.
3. Review DEPLOYMENT_GUIDE.md if you plan to deploy this to a production server.

The application uses FastAPI for the backend and a premium HTML/Tailwind CSS frontend.
