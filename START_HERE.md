# Start Here

Welcome! This document will guide you through the contents of this directory.

## What is this?
This is a predictive marketing platform tailored for the automotive industry. It takes a Jupyter Notebook analysis and converts it into a full-fledged web application.

## Core Files:
- `app.py`: The FastAPI server that loads the ML model and serves the API and web UI.
- `index.html`: The beautiful, responsive frontend dashboard.
- `champion_model.pkl`: The serialized Gradient Boosting model.
- `run_ml_pipeline.py`: A stub script for model retraining operations.
- `requirements.txt`: Python dependencies needed to run the app.
