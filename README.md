# Automotive Lead Conversion App

## Overview
A web application built with FastAPI and Tailwind CSS to serve a machine learning model predicting automotive sales lead conversion.

## Features
- Real-time conversion probability prediction.
- Premium, dark-themed UI dashboard.
- Model performance and feature importance analytics using Chart.js.

## Tech Stack
- Backend: Python, FastAPI, Scikit-Learn, Pandas, Joblib
- Frontend: HTML, Tailwind CSS, Chart.js

For running instructions, see `QUICKSTART.md`.
